
ZOONL LIVE

ZOONL LIVE is a Flutter-based social live-streaming application.

About

ZOONL LIVE aims to provide a global social platform where users can connect, join live rooms, interact with others, and enjoy social entertainment features.

Planned Features

- Live Audio and Video Streaming
- Public and Private Rooms
- Virtual Gifts
- Coins and Diamonds
- VIP Membership
- Games and Live Filters
- User Verification
- Agency Management
- Owner-Controlled Admin Panel

Current App Status

The current version includes:

- Dark-themed home screen
- Sample live rooms
- Feature highlights
- Bottom navigation

Some features are currently placeholders and require backend and service integration.

Getting Started

Install the Flutter SDK:

https://docs.flutter.dev/get-started/install

Run these commands in the project terminal:

flutter pub get
flutter run

Run Tests

flutter test

Build APK

flutter build apk --debug

Future Development

The next development stages include authentication, Firebase integration, live streaming services, virtual gifting, user accounts, and admin management.
